# THERMAVEXIA
## Thermal Intelligence & Monitoring Platform

**Research Title:** *Design and Thermal Analysis of a Passive Cooling Mechanism for Sealed Titanium-Enclosed Electronics in Underwater Applications.*

---

## 1. Project Overview

THERMAVEXIA is a real-time thermal monitoring and intelligence web platform engineered to evaluate passive heat dissipation in underwater electronic enclosures. 

In submerged subsea systems, sensitive computing electronics are hermetically sealed inside an air-tight titanium pressure enclosure. To prevent overheating without failure-prone active cooling fans, heat is conducted away from internal components through a high-conductivity solid copper rod directly to an external marine heat sink.

THERMAVEXIA monitors this passive thermal conduction pathway using two precision digital Dallas DS18B20 temperature sensors connected to an ESP32 microcontroller:
- **T1 (Internal Enclosure Temperature):** Measures internal ambient core heat generated by electronics.
- **T2 (External Copper Rod Temperature):** Measures heat arriving at the external copper conduction rod.
- **ΔT (Thermal Difference = T1 - T2):** Characterizes the temperature gradient driving conductive heat transfer.

Readings are displayed locally on an on-device 0.96" I2C OLED screen and streamed directly to this web application via **USB Serial (Web Serial API)** at 115200 baud.

## 3. Hardware Configuration & Wiring

### Components
1. **ESP32 DevKit V1** (Microcontroller with USB CDC Serial)
2. **2× DS18B20 1-Wire Digital Temperature Sensors** (Waterproof probe recommended)
3. **1× 4.7 kΩ Resistor** (Required pull-up resistor between 1-Wire DATA and 3.3V)
4. **1× 0.96" SSD1306 I2C OLED Display (128×64 pixels)**
5. **Breadboard & Jumper Wires**
6. **Micro-USB to USB-A Cable** (Data transfer cable)

### Pinout Connections

| Sensor / Module | ESP32 Pin | Details |
| :--- | :--- | :--- |
| **DS18B20 VCC** | `3V3` or `VIN` (5V) | Power supply |
| **DS18B20 GND** | `GND` | Common ground |
| **DS18B20 DATA** | **`GPIO 4`** | Both sensors share GPIO 4 with a 4.7kΩ pull-up to 3.3V |
| **OLED VCC** | `3V3` | 3.3V Power |
| **OLED GND** | `GND` | Ground |
| **OLED SDA** | **`GPIO 21`** | I2C Data |
| **OLED SCL** | **`GPIO 22`** | I2C Clock (Address: `0x3C`) |

> **Wiring Note on DS18B20:** Both DS18B20 sensors share the exact same Data pin (`GPIO 4`) via the Dallas 1-Wire bus protocol. Ensure a 4.7 kΩ pull-up resistor is placed between `GPIO 4` and `3.3V`.

## 4. ESP32 Firmware Upload Instructions

### Prerequisites
1. Install the [Arduino IDE](https://www.arduino.cc/en/software) (Version 2.x recommended).
2. Install the **ESP32 Board Package**:
   - In Arduino IDE, open **File > Preferences**.
   - In *Additional Board Manager URLs*, add:
     `https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json`
   - Open **Tools > Board > Boards Manager**, search for `esp32` by Espressif, and click **Install**.
3. Install the required libraries via **Sketch > Include Library > Manage Libraries**:
   - `OneWire` by Paul Stoffregen
   - `DallasTemperature` by Miles Burton
   - `Adafruit SSD1306` by Adafruit
   - `Adafruit GFX Library` by Adafruit

### Flashing Procedure
1. Connect the ESP32 to your computer using a USB cable.
2. Open `esp32_code.ino` in Arduino IDE.
3. Select your board under **Tools > Board > esp32 > DOIT ESP32 DEVKIT V1** (or your specific board variant).
4. Select the corresponding serial port under **Tools > Port** (e.g., `COM3` on Windows or `/dev/cu.usbserial...` on macOS/Linux).
5. Click **Upload**.
6. Once uploaded, the OLED will show `"THERMAVEXIA / Starting..."` followed by live temperature readouts.

## 5. Website Launch Instructions

Because THERMAVEXIA is built using modern standards-based HTML, CSS, and Vanilla JavaScript, it does not require Node.js, Webpack, or npm.

### Option A: Local Testing with Any Static Web Server
The Web Serial API requires a **Secure Context** (`localhost` or `https://`). Do not double-click `index.html` as `file:///` because browsers restrict Web Serial in raw file contexts.

Run any local web server from the project directory:
```bash
# Using Python 3:
python -m http.server 8000
```
Then open Google Chrome or Microsoft Edge and navigate to:
```
http://localhost:8000
```

### Option B: VS Code Live Server
1. Open the `THERMAVEXIA` folder in Visual Studio Code.
2. Install the **Live Server** extension.
3. Right-click `index.html` and click **Open with Live Server**.

## 6. USB Serial Connection Procedure

1. Connect the ESP32 to your PC with the USB cable.
2. Open THERMAVEXIA in **Google Chrome** or **Microsoft Edge**.
3. Click the **Connect ESP32** button in the header.
4. A browser dialog will appear listing available USB serial COM ports.
5. Select your ESP32 (e.g., `CP2102 USB to UART Bridge Controller` or `USB-SERIAL CH340`) and click **Connect**.
6. The connection indicator will turn green (`CONNECTED`), the port name will appear, and telemetry will update in real time at 1 Hz.

## 7. Supported Browser Requirements

Web Serial API is a W3C standard implemented natively in Chromium-based desktop browsers:
- **Supported:** Google Chrome (Desktop, version 89+), Microsoft Edge (Desktop, version 89+), Opera, Brave.
- **Unsupported:** Mozilla Firefox, Apple Safari, iOS browsers (Apple WebKit does not expose serial ports).
- If an unsupported browser is detected, THERMAVEXIA will automatically display an informational banner guiding the user to Chrome or Edge.

## 9. Features & Usage Guide

### 1. Main Measurement Cards
- **Card 1 (Inside Temperature):** Real-time internal core sensor reading (T1) in °C with min/max tracking.
- **Card 2 (Outside Temperature):** Real-time external copper rod reading (T2) in °C with min/max tracking.
- **Card 3 (Temperature Difference):** Dynamically calculated thermal gradient ($$\Delta T = T1 - T2$$).
- **Card 4 (Operational Status):** Real-time status (`Monitoring`, `Warning`, `Critical`, or `Sensor Error`) with packet frequency.

### 2. Dual-Line Live Graph
- Plots T1 (Orange) and T2 (Cyan) simultaneously on a rolling time window.
- Toggle between `30 pts`, `60 pts`, and `120 pts` time window scales.
- Interactive tooltip reveals exact values and calculated $$\Delta T$$ on mouse hover.
- Click **Reset Graph** to clear history when starting a new experimental trial.

### 3. Thermal Data Logger & CSV Export
- Click **Start Recording** to begin logging every valid packet with ISO 8601 timestamps.
- Live sample counter and session elapsed timer show active recording state.
- Recent readings preview table displays the latest 25 recorded points.
- Click **Download CSV** to immediately export an RFC 4180-compliant `.csv` file formatted for Excel, MATLAB, Python pandas, or OriginLab analysis.

### 4. Software Warning Threshold
- Customize the High Temperature Warning limit (default: 60.0°C) in the **Diagnostics & Alarm Configuration** panel.
- The interface automatically changes state to `Warning` or `Critical` if internal enclosure temperature exceeds safe research parameters.

### 5. Theme Switching
- Click the Moon/Sun icon in the top right to switch between **Dark Mode** and **Light Mode**.
- Theme choices are saved to `localStorage` and persist upon refresh.
- Chart.js gridlines, text, and tooltips re-render automatically to match the selected theme.

### 6. Offline Bench Simulation Mode
- If physical hardware is unavailable during software presentation or evaluation, click **Enable Offline Simulation** in the diagnostics panel.
- The platform simulates realistic thermodynamic heating and passive cooling curves at 1 Hz.
- An amber watermark banner clearly indicates that simulation data is active to preserve scientific integrity.

## 10. Common Troubleshooting Steps

| Issue | Cause | Solution |
| :--- | :--- | :--- |
| **"Sensor error! Check wiring" on OLED** | One or both DS18B20 sensors are not detected by ESP32 | 1. Verify 4.7kΩ pull-up resistor between GPIO 4 and 3.3V.<br>2. Ensure sensor VCC and GND pins are secure.<br>3. Confirm both sensors share GPIO 4. |
| **"OLED not found!" on Serial Monitor** | I2C communication issue with SSD1306 | 1. Check SDA is wired to GPIO 21 and SCL to GPIO 22.<br>2. Verify OLED address is `0x3C`. |
| **Browser says "Web Serial API Not Supported"** | Using Firefox, Safari, or an insecure context | Use **Google Chrome** or **Microsoft Edge** on desktop via `http://localhost` or `https://`. |
| **Port selection dialog is empty** | ESP32 driver missing or faulty USB cable | 1. Install CP210x or CH340 USB-to-UART bridge driver.<br>2. Ensure you are using a data-capable USB cable (some cables are charge-only). |
| **Serial port cannot be opened / Access Denied** | Port is occupied by Arduino IDE Serial Monitor | Close the Serial Monitor in Arduino IDE before clicking "Connect ESP32" on the website. Only one program can read the serial port at a time. |
